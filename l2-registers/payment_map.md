### Строки §1 без применимого вопроса

- Строка 7 (идемпотентный повтор `/create_order`) — вопросов не порождает: идемпотентность здесь ведётся по `CRM_Deal_ID` внутри 1С/CRM, эквайринга не касается.
- Строка 9 (автоотмена резерва самовывоза 72ч) — вопросов не порождает: деньги ещё не двигались, оплата на этой ветке впереди, на кассе (строка 10).
- Строка 10 (оплата на кассе при самовывозе) — вопросов не порождает: оплата идёт через кассу/POS на месте, а не через API эквайринга, о котором вопросы 1–20.
- Строка 11 (оплата доставки водителю) — вопросов не порождает: наличная оплата водителю не проходит через эквайринг (CON-06).
- Строка 14 (рекламация и брак) — вопросов не порождает: сама рекламация деньги не двигает (гарантийный обмен — без повторной оплаты); денежная часть при отказе от замены идёт через смарт-процесс «Возврат» (строка 13, уже покрыта вопросами 6–11).
