# BRIEF F4-05 — Снимок документации эквайера: конвертация D7 в цитируемый текст
**Тип:** script
**Суждение:** механический (ADR-029 §4)
**Класс задачи:** A. Внесение самого PDF в `l3-external/raw` было операцией класса B и
исполнено Owner коммитом `d796340b`; эта задача raw не трогает.
**Роль:** Executor (Sonnet), путь Claude Code · **Дата:** 2026-08-02 · **Автор:** Architect
**Служит:** Ф-3 — без построчно цитируемого текста документации эквайера механику
автовозврата спроектировать нельзя: вывод без цитаты `файл@SHA:строки` статуса не имеет (К-1).

## Цель
В репо появляется текст документа D7 с построчной адресацией и постраничными маркерами,
число извлечённых страниц сходится с числом страниц оригинала, страницы с непригодным
извлечением выписаны отдельным перечнем числом, опись корпуса дополнена строкой фрагмента.
После этого на D7 можно ссылаться как на D1–D6.

- l3-external/MANIFEST.md — строка фрагмента в таблице «Фрагменты»

## Входы и факты
- Порядок внесения документации задан ADR-063 §4: текст добывает скрипт, не модель (К-26);
  страницы с непригодным извлечением выписываются перечнем и закрываются вторым проходом.
- Провенанс PDF уже зафиксирован в `l3-external/MANIFEST.md` (блок «D7 — отдельный
  провенанс»): 1 291 613 байт, sha256 первые 16 `91e4b56fccac0cba`, 27 страниц,
  генератор Microsoft Word 2019. Сверить фактически, расхождение — стоп и Architect.
- `l3-external` immutable (К-3): файл md после коммита не редактируется; исправление —
  новый файл с новой датой.
- Пустой вывод результатом не является; критерий формулируется числом (К-28).
- Замер без артефакта не существует (К-22): все числа ложатся в отчёт файлом.

## Шаги
1. Убедиться, что доступны `pdftotext`, `pdfinfo`, `pdfimages` (пакет poppler-utils).
   Недоступны — установить; факт и версию записать в отчёт.
2. `pdfinfo l3-external/raw/AlatauCityBank_ecom.pdf` — зафиксировать число страниц (P) и
   размер файла; `sha256sum` — первые 16 символов. Сверить с блоком провенанса в MANIFEST.
3. Написать `tools/pdf_to_md.sh`: для каждой страницы N от 1 до P выполнить
   `pdftotext -layout -f N -l N <pdf> -`, перед выводом страницы напечатать строку-маркер
   `<!-- PAGE N -->`, весь результат собрать в `l3-external/md/d7_t01_acquiring_api.md`.
   Скрипт — единый copy-paste-ready блок, все значения литеральные, плейсхолдеров нет (К-6).
4. Прогнать скрипт. Посчитать: число маркеров `<!-- PAGE` в получившемся файле; общее число
   строк файла; для КАЖДОЙ страницы — число непробельных символов.
5. `pdfimages -list` — число изображений по страницам. Свести таблицу
   «страница / непробельных символов / изображений».
6. Кандидаты на второй проход: страницы с числом непробельных символов ниже 200 ЛИБО с числом
   изображений больше нуля при числе символов ниже 600. Перечислить номерами; кандидатов нет —
   написать «кандидатов: 0».
7. Собрать `reference/2026-08-02_d7_extraction_report.md`: дословные команды, версия
   `pdftotext`, sha256 первые 16 и размер PDF, число страниц, таблица шага 5 целиком,
   перечень кандидатов шага 6, число строк итогового md.
8. Дополнить таблицу «Фрагменты» в `l3-external/MANIFEST.md` строкой:
   файл `md/d7_t01_acquiring_api.md` · документ D7 · вкладка «—, PDF постранично» ·
   число строк · sha256 первые 16 итогового md.

## Критерии приёмки
- Число маркеров `<!-- PAGE` в `l3-external/md/d7_t01_acquiring_api.md` равно числу страниц
  из вывода `pdfinfo`. Ожидаемое значение — 27; фактическое расходится → стоп и Architect,
  самостоятельного объяснения не строить.
- В таблице отчёта присутствует строка на каждую из P страниц; пропущенных номеров нет.
- Перечень страниц-кандидатов на второй проход выражен числами, в том числе «0».
- sha256 и размер PDF в отчёте совпадают с блоком провенанса MANIFEST; расхождение — стоп.
- Строка фрагмента в MANIFEST добавлена, sha256 итогового md проставлен.
- Формулы в задаче нет (К-32).

## Return-this
Пути четырёх записанных файлов; дословный вывод проверок приёмки (числа, не метки);
перечень страниц-кандидатов. Плюс session-блок по `docs/04_SESSION_PROTOCOL.md` (обязателен).

## Вне scope
Не читать документ содержательно и не делать никаких выводов о возможностях эквайринга:
чек-лист возможностей — задача F4-06, отдельный бриф. Не заполнять ни одной строки о
двухстадийности, возвратах, сроках. Не править `l3-external/raw` (класс B). Не выполнять
второй проход по страницам-картинкам: эта задача его только назначает. Не редактировать
ранее закоммиченные файлы `l3-external/md/` (К-3). `git push` не выполнять.
