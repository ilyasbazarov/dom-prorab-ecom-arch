## Легенда колонок (ADR-060)

**Состояние.** не начата · в работе · сделана · заблокирована (в скобках — чем).
**Путь.** чат либо Claude Code. Перечень ролей, допущенных внутрь Claude Code, живёт в
`CLAUDE.md` §Мандат в единственном экземпляре (ADR-049 §3, ADR-059 §1).
**Параллель.** «можно» либо «едет одна» с причиной. Заполняется по наборам файлов на запись
(К-31): пересечение наборов даёт «едет одна». «Можно, после волны M2» означает, что условие о
непересечении файлов выполнено, а два остальных условия ADR-037 §1 (буфер и сборщик
установлены; обе задачи класса A) ещё нет. Любая необратимая операция класса B не параллелится
независимо от файлов (ADR-037 §3).

P-13 (кладовщик в двух системах) — операционная политика, идёт входом в Business-сессию (F4-01).
Фаза 4, вторая половина: `l0-canon/business_canon.md` — Business-сессия, вход готовит бриф F4-01.

## Правило
Задача попадает в работу только через бриф. Брифы — `briefs/<ID>.md`, ID: `B<n>` (Track B, волна n), `F<фаза>-<nn>` (Track A). Метки трассировки в регистрах — по задаче (`B1-Pxx`, `F5-01`), они не обязаны совпадать с именем файла брифа.
