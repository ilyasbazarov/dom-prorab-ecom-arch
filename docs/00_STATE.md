строк, лимит 25 строк на текст к Owner, форма «тезис плюс одна поясняющая фраза», коды без
расшифровки, хвостовых блоков нет. Носители К-38 в промтах пяти ролей (по два места в
каждом) вынесены в пачку C отдельной сессией, развилка Р-2.
