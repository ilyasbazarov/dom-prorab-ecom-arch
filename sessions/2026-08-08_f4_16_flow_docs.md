## Решения по форме, принятые внутри задачи

Бриф объявил задачу «с суждением» в части формы изложения наружу. Принято три решения, все
названы в ADR-102:

- **Идентификаторы тикетов волны 1** (§5 записи). Оба пакета от 2026-08-03 нумеровали задачи
  «Задача 1…4», служебное приложение с именами `BITRIX-B1-xx` и `1C-B1-xx` перед отправкой
  удалялось, поэтому подрядчики этих имён не видели. В документе Bitrix-подрядчика задачи названы
  только номерами пакета; в документе List.kg номер дополнен идентификатором в скобках, потому что
  письмо C редакции 2 уже употребляло `1С-B1-09` и `1С-B1-05` открытым текстом и на эту форму
  опирается отмена двух критериев приёмки.
- **Коллизия разрешённого кода адресата с запрещённым классом** (§4 записи): разрешает решение, а
  не приёмка; шаблон проверки не ослабляется.
- **Расхождение с письмом C редакции 2 по числу стадий без носителя статуса** (§6 записи): письмо
  называло пять, после патча канона 2026-08-07 их девять, в документ перенесены девять. Снимок не
  правится (К-33).
