# Пусковое сообщение: заход Reviewer на пять записей метода

Как пользоваться: открыть новую сессию Claude Code в корне клона, скопировать блок ниже
ЦЕЛИКОМ и вставить одним сообщением. Слотов на заполнение в нём нет ни одного — ни SHA, ни
предмета (ADR-117 §1): на пути Claude Code роль берёт SHA сама командой `git rev-parse HEAD`.
Ничего не редактировать перед вставкой.

Адреса в блоке выверены на коммите, который вносит этот файл, и указанных участков не касаются
никакие правки того же коммита. SHA в блок не зашит намеренно: роль берёт его сама и предъявляет
адреса на нём (К-36). Если до запуска в дерево лягут другие коммиты, трогающие журнал решений,
конвенции, промты или проверки, номера строк уедут — тогда файл ПЕРЕСОБИРАЕТСЯ сессией, а не
правится руками; несовпадение хотя бы одного адреса роль обязана трактовать как стоп.

## Что Owner получает на выходе

Список находок с уровнями и вердикт по каждой из пяти записей: можно переводить в `accepted`
или нельзя. Находка уровня STOP хотя бы по одной записи означает, что апрув откладывается до
её закрытия; FIX и NOTE апруву не мешают, но остаются работой Architect.

Заход не назначает себе продолжения: если Reviewer найдёт, что предмет шире пяти записей,
он говорит это строкой, а расширение решает Owner.
