## §1 Воронка сделки CRM — не подтверждена заведённой; это не «доступ», а предмет проверки

Все шестнадцать шагов объёма выражают ожидаемое следствие стадией воронки
(`l0-canon/order_flow_e2e.md@2708bef:931-983`, закрытый перечень четырнадцати стадий). Воронка
заводится руками Owner строкой 13 очереди (`docs/05_ROADMAP.md@2708bef:92`), её приёмка — снимок
`crm.dealcategory.stage.list` в `reference/` с числами 14 / 0 расхождений имён / 0 лишних
(ADR-100 §5).

Замер: файлов такого снимка в `reference/` — **0**.

```
ls reference/ | LC_ALL=ru_RU.UTF-8 grep -i -E "stage|воронк|dealcategory"   → 0 строк
```

Следствие, которое ADR-135 не учла: без заведённой воронки не работает и ручной способ
предусловия из ADR-135 §3 — выставить руками стадию, которой в портале нет, нельзя. Строка 13
есть гейт прогона, а не параллельная дорожка, как её описывает `docs/00_STATE.md@2708bef:20`.
