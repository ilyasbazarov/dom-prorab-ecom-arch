2. Дефект самой формы

Класс [А-Я] не включает Ё. Под этой формой пять вхождений слов с Ё (НЕЧЁТНЫЕ 1,
НЕЧЁТНЫХ 1, СВОЁМ 2, ЧЁТНЫХ 1) из счёта выпадают, а вместо них появляются три обрывка
(ТНЫХ 2, ТНЫЕ 1), словами не являющиеся.

LC_ALL=ru_RU.UTF-8 git grep -o -h -P "[А-ЯЁ]{4,}" 7b556fa -- ':!l3-external' | wc -l → 348

Арифметика: 348 − 5 + 3 = 346. Корректная форма — [А-ЯЁ], корректное число — 348.
На вывод ADR-047 §Контекст («риск не гипотетический») разница не влияет: оба числа
поддерживают его одинаково, ни одно суждение записи не меняется. Значение 346, названное
ADR-047, командой подтверждено и остаётся в обращении; корректная форма даёт 348.
Класс кириллицы без Ё — вторая тихая ловушка того же рода, что байтовая локаль (К-35):
выдача занижается без сообщения об ошибке. Заведена строкой в docs/00_STATE.md
§Открытые вопросы (К-23).
